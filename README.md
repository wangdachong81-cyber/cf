# 几猫 · 港区混战

基于 **Vite、TypeScript、Three.js、Node.js 和 WebSocket** 的浏览器多人第一人称枪战游戏。玩家随机进入港区集装箱地图，全员互为对手；观战者通过俯视地图上的彩色圆点实时观察战局。

本项目沿用原始单文件 HTML 的 WebGL 技术方向，重新拆分为前端、权威游戏服务端与共享规则三个部分。原型文件 `几猫国产3A大作_V1.html` 保留作为参考，新工程不依赖该文件运行。

## 已实现

- **房间联机**：创建房间、6 位房间号加入、开放房间列表、邀请链接、昵称、退出及断线清理。
- **个人混战**：最多 8 人参战，所有其他玩家都是对手。至少 2 人后开始计分，单人时可自由熟悉地图。
- **第一人称射击**：移动、冲刺、跳跃、瞄准、自动步枪、30 发弹匣、换弹与射击音效。
- **服务端判定**：统一处理移动、碰撞、射速、弹药、射线命中、障碍物遮挡、伤害和计分。
- **随机出生与复活**：从有效位置中优先选择远离其他玩家的出生点。死亡 3 秒后复活，出生保护 2 秒，开火立即取消保护。
- **对局循环**：每局 5 分钟或先到 20 次击杀结束；按击杀数降序、死亡数升序排名，同分同死亡并列获胜；10 秒后自动准备下一局。
- **俯视观战**：每人一个独立颜色圆点，显示昵称、朝向、出生保护和死亡状态；最多 16 位观战者，不占参战席位。
- **战场界面**：生命、弹药、击杀播报、排名、延迟、结算与音效开关。

## 本地开发

需要 Node.js **22.12 或更新版本**，推荐 Node.js 24。

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。开发命令同时启动 Vite（5173 端口）和游戏服务（3001 端口），Vite 代理 `/ws` 和 `/api`。

联机体验：打开多个浏览器窗口，分别填写昵称；第一个窗口创建房间，其他窗口用房间号加入。选择「俯视观战」后加入同一房间即可查看实时位置。

**局域网联机**：其他设备访问启动日志里的 `Network` 地址，例如 `http://你的局域网IP:5173`，并使用同一房间号。需要设备在同一网络，且系统防火墙允许 5173 端口连接。房间链接中的 `localhost` 仅供本机访问，邀请其他设备时请使用局域网地址。

## 构建与运行

```bash
npm run check
npm test
npm run build
npm start
```

生产服务默认监听 `0.0.0.0:3001`，同时提供构建后的网页、HTTP API 与 WebSocket。可使用环境变量 `PORT` 修改端口：

```bash
PORT=8080 npm start
```

部署到公网时，需要支持持续运行 Node.js 和 WebSocket 的主机。通过 HTTPS 反向代理 `/` 和 `/ws` 到同一服务；网页会自动使用 WSS。不要只上传 `dist` 到静态托管，否则无法进行多人对战。

## 工程结构

```text
src/
  client/
    main.ts         大厅、输入、网络同步与 HUD
    scene.ts        Three.js 场景、角色、武器与射击表现
    map.ts          俯视观战地图
    audio.ts        合成射击音效
    style.css       界面样式与响应式布局
  server/
    index.ts        HTTP、WebSocket、房间连接与心跳
    game.ts         权威对局模拟、复活、命中和计分
  shared/
    config.ts       地图、武器与对局参数
    physics.ts      前后端共用碰撞与移动逻辑
    protocol.ts     网络消息和游戏状态类型
tests/              规则测试与真实 WebSocket 联机测试
```

修改 `src/shared/config.ts` 可调整地图障碍、房间人数、移动速度、武器伤害、复活时间和对局规则。

## 同步方式与当前边界

服务端以 30Hz 模拟并广播状态，客户端进行本地移动预测与输入确认后的重算，其他玩家使用位置插值。命中使用服务端当前状态的即时射线，暂未加入历史回溯补偿，因此高延迟网络下射击体验仍有优化空间。

首版优先支持桌面端键鼠，移动端可浏览大厅与观战，尚未实现触控射击。当前包含一张地图和一把武器，无账号、排位、持久化战绩或断线自动恢复。房间存在进程内存中，服务重启后清空，暂按单实例部署。

本地验证覆盖构建、游戏规则和真实多客户端 WebSocket 流程。浏览器自动化预览连接未成功，完整的实际手感和视觉效果仍需在桌面浏览器中验收。
