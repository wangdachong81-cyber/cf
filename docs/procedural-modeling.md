# 原版机械猎犬与人物建模

原型的机械猎犬完全由代码生成，原型函数 `Z_()` 构造几何，`iu` 组织骨骼和材质槽，`pm()` 创建 `SkinnedMesh`、`Bone` 和 `Skeleton`，`q_()` 求解腿部 IK，`iM()` 管理四足步态及机身弹性运动。原型文件已由用户删除，仍可在本仓库早期提交中查看源文件。

- 20 根骨骼：根、机身、脖子、头、炮塔、枪、天线、信标，以及四条腿各三个关节。
- 倒角装甲板、圆柱关节、螺栓、散热鳍片、管线和传感器组成形体；顶点颜色辅助表现明暗。
- 几何按 shell / metal / glow / lens 四种材质槽合并；一个蒙皮网格可以包含多个材质绘制组，并不等于只有一次绘制。
- 每个硬表面顶点刚性绑定到一根骨骼，权重为 1，无外部模型或动作文件。
- 脚掌保存世界空间落点，交替抬起对角两足。双节腿 IK 根据脚的位置求髋、膝角度；机身、天线用弹簧阻尼响应移动、转向和射击。

## 人物采用的方法

当前使用 `soldier.ts` 生成现代战术士兵：以平滑的椭圆截面、褶皱和程序化迷彩形成军服与裤腿，增加战术背心、MOLLE 织带、弹匣包、背包、头盔、护目镜、面罩、护膝和作战靴。外观参考经典竞技 FPS 的战术风格，未使用 CF 的模型或素材。`character.ts` 保留为原有机械装甲方案，目前场景使用士兵方案。

`viewmodel-hands.ts` 直接复制原版第一人称的左右手网格，包括弯曲手指、手套护垫、缝线和袖子，沿用原材质及握枪姿势。复制几何后再烘焙全身骨骼，避免释放或修改第一人称仍使用的几何；保留平滑法线，避免曲面变为多边形硬面。上臂与肩部重新生成，用来把原版前臂接入身体。

第一人称的镜头空间动画不能直接作为第三人称全身动画。当前全身有独立的瞄准、呼吸、行走、腾空与简化换弹姿态；手指沿用原版握枪的静态弯曲形状，尚无逐指换弹动作。

`rig.ts` 将零件烘焙到同一个材质分组蒙皮网格：生成刚性骨骼索引和权重，然后合并几何。所有玩家共享几何和大部分材质，使用独立骨架与身份色材质；离开房间时释放自己的骨骼纹理，不销毁共享几何。

人物腿部同样使用双节腿 IK，根据步态的支撑和摆动阶段确定脚的位置，踝关节反向补偿以维持脚底朝向。与原版猎犬相比，人物目前使用角色局部空间的目标脚步，不是逐足追踪世界空间落点；还不能声称完全消除了滑步。

所有形状、材质和动作都由本地代码生成，不使用外部美术资源。
